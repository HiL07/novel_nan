# 封面与版权核查清单（交付前必走）

脚本只处理 .docx **文本**，**封面图内容、跨库版权比对脚本无法覆盖**——这是本 skill 的能力边界，
不可隐瞒。但 v1.9.0 起，文本层版权风险已由 `scripts/copyright_scan.py` 自动挖出候选，
本章把"能自动的"和"必须人确认的"分开，避免"完全帮不上忙"。

## 先分清：自动 vs 人工

| 检查项 | 谁做 | 工具 / 方式 |
|---|---|---|
| 正文文本版权风险（明星名/IP/歌词/同人/商标） | 脚本自动挖候选 | `scripts/copyright_scan.py <_过审版.docx> --out 版权风险报告.md` |
| docx 书名 / 笔名属性是否与后台一致 | 可人工核对文本 | 打开 docx 属性 + 后台对照 |
| 封面图内容（暴露/侵权底图/真人明星/AI水印） | **必须人确认** | 肉眼看图 |
| 跨库版权比对（是否撞车他人作品） | **必须人确认** | 查重工具 / 人工 |
| 独家合约冲突（多平台首发） | **必须人确认** | 作者自查合约 |

> 脚本跑完 `copyright_scan.py` 后，把报告丢给用户："以下是正文里疑似侵权的引用，请你逐条确认是否授权/合理使用。"——这比"你自己检查版权"具体得多。

## 脚本自动查（v1.11.0 起：把"必须人确认"降到"点两下"）

封面图内容脚本确实看不见，但**客观指标可机器测量**。v1.11.0 让 agent 用脚本预填体检单，
把"封面须人确认"从"自己拿尺子量 + 凭空想"降为"就 3 项点一下"：

1. **封面客观指标 → `scripts/cover_check.py <封面图路径> --out 10_cover.md` 自动查**：
   格式 / 像素尺寸 / 宽高比(竖向3:4) / 文件大小 / 是否接近纯色(疑似默认模板)。
   这几项机器出结论，agent 不用问用户。
2. **正文版权风险 → `scripts/copyright_scan.py` 自动挖候选**（明星名/IP/歌词/同人/商标）。
3. **仍须人确认、但用选择题式提问（非填空）的仅 3 项**：
   - 真人肖像（封面是否用真人/明星脸？有/无/不确定）
   - 第三方 IP 元素（是否含他人角色/品牌 logo？有/无/不确定）
   - 政治敏感地标（有无敏感建筑/旗帜？有/无/不确定）
   > 文字占比是否超标(≤15%) 用户目测即可，agent 给一句提醒不必追问。

**agent 引导式确认话术**（替代"请确认封面 8 项"）：
> "封面尺寸/格式/比例我已自动查完（见 10_cover.md，均达标）。只剩 3 个我看不见的点要你拍板：
> ① 封面有没有用真人照片？② 有没有第三方 IP/品牌元素？③ 有没有政治敏感地标？
> 三项都选'无'即可送审；任一'有'请告诉我具体是什么。"

→ 这样用户只需点 3 下，而非读 8 条清单 + 自己判断。

## 一、封面核查（8万字推荐评估硬性门槛）—— 全部必须人确认

逐项勾选（通过 / 存疑 / 不通过 + 备注）：

- [ ] **书名清晰**：封面书名与正文/后台书名完全一致，无错别字、无遮挡。
- [ ] **笔名清晰**：封面上有笔名，且与后台签约笔名一致。
- [ ] **非模板封面**：未使用平台默认模板封面（模板封面进不了推荐验证）。
- [ ] **题材匹配**：封面风格与题材一致（都市文不玄幻脸、年代文不现代装）。
- [ ] **无版权风险素材**：封面图非网图盗用、非真人明星照、非 AI 生图带水印 logo。
- [ ] **分辨率达标**：不低于番茄后台要求的最低分辨率（一般 ≥600×800，无拉伸模糊）。
- [ ] **无擦边元素**：封面人物无低俗暴露、暗示性姿态（否则命中"封面不合适"驳回）。
- [ ] **文字可读**：书名在缩略图尺寸下仍清晰可辨（手机信息流是小图曝光）。

**建议话术**：把封面设计要点给用户——红黑撞色高点击、书名占画面 1/3、
题材符号前置（系统文放终端/光脑元素，重生文放年代符号）。

### 封面客观可自查项（用户能自己快速过的硬标准，降低"完全帮不上忙"感）

脚本看不见图，但以下"客观标准"你可以照着逐条自查，不必等设计师反馈：

- [ ] **尺寸合规**：竖版封面 ≥ 600×800 px（一般要求 ≥ 600×800，无拉伸模糊、无白边）；分辨率不足会被后台拒。
- [ ] **文字占比 ≤ 15% 画面**：书名 + 笔名占画面不超过 1/3，手机缩略图（约 1 寸见方）下仍清晰可辨——信息流是小图曝光，字挤成一团等于没书名。
- [ ] **无真人肖像**：不用真人明星/网红/模特照（含 AI 换脸），否则命中"封面不合适"且涉肖像权。
- [ ] **无第三方 IP 元素**：不出现他人作品角色、知名动漫/影视/游戏形象、品牌 Logo（如直接用"火影""漫威""某车企标"），否则版权瑕疵。
- [ ] **无政治/敏感地标**：不出现敏感地标、国旗国徽、真实机构标识的滥用。
- [ ] **无擦边姿态**：人物无低俗暴露、暗示性动作/眼神/肢体接触（否则命中"封面不合适"驳回）。
- [ ] **非平台默认模板**：未用番茄/第三方默认模板封面（模板封面进不了推荐验证）。

> 红线认知补强：封面是"8万字推荐评估"的**硬性门槛**——封面不过，评估直接不通过。
> 以上 7 条是用户自己能 5 分钟过一遍的客观项；拿不准的（是否擦边、是否撞 IP）再问设计师或自查工具（图片溯源：百度识图）。

## 二、版权核查

- [ ] **原创声明**：作品为原创或已获授权，无抄袭段落。
- [ ] **无同人/影视素材**：未使用他人 IP 世界观、角色名、专有名词（脚本已扫正文疑似项，见 `copyright_scan.py` 报告）。
- [ ] **无洗稿痕迹**：非对他人大纲/剧情走向的高仿改写。
- [ ] **笔名合规**：笔名未与知名作者雷同，不含违禁词。
- [ ] **素材引用**：正文中引用的歌词/诗句/梗，注明来源或确认在合理使用范围（脚本已扫长引用/标记）。
- [ ] **多平台首发问题**：若作品曾在其他平台发布，确认无独家合约冲突。

## 三、确认动线（交付前必走）

1. 交付 `_去AI过审版.docx` 时，先跑 `copyright_scan.py` 生成版权风险报告，附在交付物里。
2. 列出本清单两项的未确认项。
3. 用 AskUserQuestion 让用户逐块确认：「封面 8 项是否全部满足？版权 6 项是否全部满足？」
4. 用户确认"是" → 交付完成；确认"否"或部分 → 在交付说明里用**加粗**标注未确认项及风险：
   - 封面未过 → 硬性门槛不过，推荐评估直接不通过。
   - 版权存疑 → 下架+封笔名风险，比内容驳回严重一个量级。
5. 用户拿不准的项，给自查工具建议（查重：PaperPass/句易网；图片溯源：百度识图）。

## 红线认知

- **版权瑕疵的后果量级 > 内容驳回**：内容驳回可改后重提（8万字评估有 3 次机会），
  版权问题直接下架、扣信用分、严重者封号。宁可保守，不可侥幸。
- **脚本能做的极限**：正文文本的侵权式重复（自我复制章节）、明星名/IP/歌词/同人/商标的
  **疑似引用挖掘**；封面图片质量、跨库比对，脚本做不了，必须人确认。
