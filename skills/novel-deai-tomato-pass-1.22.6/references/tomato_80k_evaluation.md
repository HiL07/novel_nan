# 番茄免费小说8万字推荐评估攻略

番茄免费小说的8万字审核（推荐评估）是作品获取流量的关键节点。核心规则：连载作品达8万字可主动申请，仅3次评估机会（含平台15万字自动发起），3次未过永久无推荐；通过后进入7天小流量验证期，达标才进正式首秀。

需从准备、内容、验证期三阶段自查，重点避坑。

---

## 一、评估前准备（硬性门槛，缺一不可）

### 1. 字数与更新
- 满8万字方可申请。
- 提交前连续3天日更≥4000字（请假需重算），避免断更或凑字数。
- 断更或单日不足4000字都会导致资格重置。

### 2. 封面/书名/简介
- 封面须含**清晰书名 + 笔名**，风格匹配内容。
- 慎用平台模板封面（易触发自动审核，消耗评估名额）。
- 书名抓眼球、无歧义；简介一句话点出核心卖点。
- 自设计封面需查底图侵权与尺度。

### 3. 状态与撤回
- 保持连载状态。
- 点击"开启推荐评估"后**不可撤回**，务必打磨到位再提交。
- 三次机会用尽即永久终止推荐，不可逆。

---

## 二、内容核心避坑（决定评估成败）

### 1. 开篇钩子（重中之重）
- 前三章300-1000字内亮出**冲突/金手指**。
- 用剧情渗透设定，严禁大段世界观/技能堆砌（如种族、进阶规则、力量体系说明）。
- 避免干巴巴背景轰炸——读者前30秒决定去留。
- 检查方法：把前三章的开头500字单独抽出来读，如果全是设定说明而非剧情推进，必须重写。

### 2. 剧情与节奏
- 主线清晰，每章必须推进情节。
- 忌"水文"：纯废话对话、机械罗列信息、重复描写、无意义日常。
- 章节字数1500-3000字均衡，标点规范。
- 检查方法：逐章问自己"这章删了，后面的剧情受影响吗？"如果不受影响，这章就是水文。

### 3. 原创与质量
- AI辅助需深度精修，杜绝50%以上AI直出内容（系统可识别低质AI文）。
- 人物有弧光（成长/转变），避免平铺直叙。
- 增强代入感：多用具体感官描写，少用抽象概括。
- 配合本技能 `deai_humanizer.py` 做机械层去AI味，再做人工逐章扫尾。

### 4. 排版基础
- 章节字数稳定（1500-3000字/章），忌忽长忽短。
- 分段合理，单段不超过5-6行。
- 无标点乱用（省略号连用、感叹号堆叠、中英标点混用）。
- 段落不过长，适当留白。

## 三、验证期操作（影响后续推流）

### 1. 更新稳定
- 通过评估后进入7天小流量验证期。
- 7天内日更≥4000字，断更或低于4000字均算**无效更新**，直接影响数据。
- 提前存稿应对突发情况。

### 2. 数据心态
- 小流量池数据（如百级阅读、个位数加书架）属正常，不必焦虑。
- 重点看**留存率**（读者从第1章读到第N章的比例），而非绝对数据。
- 留存率达标 → 进入正式首秀 → 大流量推荐。

### 3. 字数达标
- 验证期结束时需满10万字，否则无法进入首秀。
- 提前规划：8万字过评估 → 7天验证期日更4000 → 验证期结束28,000字 → 总计108,000字达标。

### 4. 申诉通道
- 对结果有异议可联系客服申诉。
- 3次失败后永久终止推荐，不可再申诉。
