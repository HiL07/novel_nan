# L3 精修 SOP（agent 辅助重写）：把"靠感觉"变成"按模板定向重写"

> 本文件是给**执行 skill 的 agent（我）**用的。v1.6.0 的 `auto_rewrite.py`（L2.5）已自动修掉
> 情绪直陈/陈词比喻/套路转场/扩展填充词/标签烂副词五类机械型 AI 味；但剩下这几类
> **需要品味和语义判断**的问题，仍要人（agent）重写——本 SOP 给可直接套用的重写模板，
> 让 L3 不再是"凭感觉改"，而是"按清单逐模式改写 + 判定"。
>
> 配套：`manual_fix_sop.md`（哪些必须人工 + 完成判定）、`auto_rewrite.py`（L2.5 已自动修的）。

---

## 模式一：跨角色声纹趋同（L2 第 8 项）

**问题**：所有角色说话都一个腔调——"他X道""她轻声说"，读不出谁在说话。

**重写模板（先建声纹表，再逐人改）**：
1. 给每个主要角色定 1-2 个**不可替换**的语癖（不是副词，是句式/用词）：
   - 男主：短句、命令式、少用语气词（"走了。""别废话。"）
   - 谋士型：爱用反问/典故（"你当真以为……？""此局，危矣。"）
   - 活泼型：破句、口语词（"哎呀才不是——""哼，偏不。"）
2. 重写时**只动对话**，不动叙事；把"X道"后的内容换成该角色的语癖句式。
3. 用 `deai_deep_report.py` 复跑，看"跨角色口头禅"条数是否下降。

**Before/After**：
```
Before: 苏晚晴说道："你这样做是不对的，你应该好好反省。"
After : 苏晚晴把笔一搁："反省？你先把上回捅的篓子补上再说。"
```
（活泼型语癖：反问+动作带情绪，不再"说道+说教"）

## 模式二：段落同构 / 节奏均匀（L2 第 6 项）

**问题**：连续段落都是"主语+动作+感受"或"时间+事件"的同一种骨架，读着像流水账。

**重写模板（打散骨架）**：
1. 抽出连续 3 段，标出每段的"开头词 + 句式"；
2. 把 ≥2 段相同的开头换成不同切入：
   - 视角切：从"他"切到"风/灯/旁人"的环境描写开头；
   - 动作切：用动作代替陈述（"门没关严。"代替"他发现门没关严。"）；
   - 倒叙切：先抛结果再补原因。
3. 长段拆 ≤5 行；避免连续 3 句同一长度。

**Before/After**：
```
Before:
他走进房间。他环顾四周。他看见桌上有一封信。
After :
门一推就开了。屋里没人，只有桌上那封信，边角被风吹得直颤。
```

## 模式三：章尾套路（L2 第 7 项）

**问题**：每章结尾都是"他握紧拳头，暗暗发誓……""他眼神一凛，转身离去"——模板化收尾。

**重写模板（给每章一个专属收尾动作）**：
1. 列全书章尾套路词（握紧拳头/暗暗发誓/眼神一凛/转身离去/露出一抹冷笑）；
2. 每章换一个**与本章情节强绑定**的收尾：
   - 战斗章 → 收刀入鞘的细节；
   - 谋算章 → 把棋子落定的动作；
   - 情感章 → 一句没说出口的话。
3. 禁止连续两章用同类收尾。

**Before/After**：
```
Before: 他握紧拳头，暗暗发誓一定要报仇。
After : 他把那张通缉令折成方胜，塞进贴胸的口袋——仇，得用活人的办法讨。
```

---

## 模式四：段落级 tell-not-show（L2 第 2 项未覆盖处）

**问题**：L2.5 只处理"感到/觉得+情绪名词"单句；但"整段在陈述人物心情、没有画面"它改不了。

**重写模板（用事件替代形容）**：
1. 找"他很X""X充斥着房间"这类整句形容；
2. 改写成**一个具体动作或一句对话**承载该情绪；
3. 每改写一段，问："删掉这句形容，读者能从动作里读出情绪吗？"能 = 成功。

**Before/After**：
```
Before: 会议室里弥漫着压抑的气氛，所有人都很紧张。
After : 没人碰面前的茶杯。投影仪嗡了一声，最末排的人把椅子往后挪了半寸。
```

---

## 模式五：安全但空洞的总结句

**问题**：章末爱加"这一刻他明白了很多""日子就这样平静地过着"——AI 味的"感悟填空"。

**重写模板**：删。或用一件小事收（见模式三）。这类总结句 90% 可直接删，不影响剧情。

---

## 模式六：反过度平滑 / 作者声纹注入（L2 第 9 项）

**问题**：文本"过度平滑"——每句都工整流畅、挑不出错，但**没有作者/角色的口头禅，也没有故意的"卡壳"**，读着像机器在汇报。这是平台"质量审查"维度点名的高危 AI 信号（见 `references/tomato_ai_detection.md`）。

**重写模板（注入可控的不完美 + 稳定声纹）**：
1. 给叙述者 / 每个主要角色定 **1 个稳定语癖**（口语词或句式），并在多章反复出现，形成可辨识的"声纹"；
2. 在过于平滑的叙述里插入**"卡壳"**：破折号断句、句内省略号、超短句、语气词（啊/呢/吧/嘛/呗）、没说出口的内心碎碎念；
3. **长短句交错**，偶尔用"视线移开/喉头动了动/他没接话"这类不推进剧情的微动作制造毛刺；
4. 禁忌：把"卡壳"写成病句。它要的是"像人说话时的停顿与走神"，不是语法错误。

**Before/After**：
```
Before: 他走进房间，环顾四周，看见桌上有一封信。他拿起信，拆开来看。
After : 他走进房间——停了停，才往里迈步。桌上那封信，边角被风吹得直颤。他拿起，没急着拆。
```
（注入破折号停顿 + 超短句 + 不推进剧情的微描写，破掉"每句都工整"的机器节奏）

**判定**：复跑 `deai_deep_report.py`，该章"过度平滑/缺口语毛刺""作者声纹缺失"两条 WARN 应下降或消失。

## agent 执行 L3 的标准轮次（每次对话 3-5 章）

1. 跑 `deai_deep_report.py` 看 L2.5 之后还剩哪些章/哪些模式；
2. 优先啃 L2 报告里 **L2.5 未覆盖**的章（声纹/同构/章尾）；
3. 对每章按上面 6 个模板逐模式过，**只改需要改的段**，不动已干净的；
4. 改完复跑 `deai_deep_report.py` + `eval_fix_check.py` 确认：L2 评分不升、字数/对话占比/红线没回退；
5. 全书 L2 的 MUST 清零后，**随机抽 3 章出声读**，能分人、无同构、情绪靠动作 → 收工。

## 一句话

L2.5 自动修"词"，L3 模板修"句与章"。把本 SOP 的 6 个模板当作重写时的 checklist，
而不是凭语感乱改——这样人工精修可复现、可判定、不会越改越乱。
