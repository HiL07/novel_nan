# Cross-world persona cards & 试聊 (implementation reference)

> Split out of `CLAUDE.md` on 2026-11-03 (content moved verbatim). `CLAUDE.md` keeps the overview and conventions; keep this file updated when the APIs / behaviour below change.


Design details, parameters and measurements: [`docs/跨世界观角色卡.md`](docs/跨世界观角色卡.md), [`docs/试聊.md`](docs/试聊.md) (update them with any change to extraction / adaptation / checks / identity test / chat).

- **Flow**: 原型卡 (prototype: traits `{layer, kind core|adaptable, locked, provenance quoted|inferred|user, confidence, evidence}`, rules over 6 situations, expertise + `worldBound`, voice + verified lines, arc, signature, memories, `uncertain`, 20 % `holdout` for the judge) → append-only versions → 适配版本 (adaptation into a workspace's settings or a hand-written world) → confirm → 用于工作区 (snapshot into Python `novel.personas`) → writing / review / 试聊; 辨识度测试 per adaptation.
- **Provenance is decided in code**, never by the model or the frontend: Python `persona.build_prototype` (quotes verified with `material_facts.Source.locate`, unverified dropped); Java `PersonaService.saveVersion` compares with the previous version (changed → `user` + `aiText`, unchanged → previous provenance/evidence, new → `user`). Core / locked trait texts are copied by code into adaptations; `check_adaptation` → `{missingManifest, changedLocked, leaks, missingSituations, ok}`; `render_brief` builds the 【人物内核·名字】 block.
- **Python** (`app/persona.py`, routes in `main.py`): `POST /api/persona/jobs {kind: extract|test, name, aliases, whole, text, files[{id, ext}], seedFacts, maxBlocks (60), chunkChars (3000), prototype, adaptation, judgeModel?, model|local|gguf, resumeKey p<cardId>}` (same single-worker queue / job endpoints as extraction; checkpoint stages `notes` / `synth`), `POST /api/persona/adapt {prototype, world?, novelId?, wish, model|local|gguf}` → `{adaptation, usage}`, `POST /api/persona/adaptation/check {prototype, adaptation}` (no model), `POST /api/persona/chat {character, persona?, novelId?, world?, mode free|scene|interview, scene, inner, messages, summary, boost, model|local|gguf}` → `{reply, inner, summary?, summarizedUpTo?, drift?, usage}`; `GET|POST /api/gen/novels/{id}/personas` (snapshot list, whole replace).
- **Generation hooks**: `spec.build_for(novel, spec?)` = `build` + `apply_personas` (role containing 主角 → core, others → cards `persona.<name>` keyed by name + aliases, ranked before normal cards in `context.build`); `_plan` / `_review` get `personas` = rules of the persons mentioned (`prompts.plan_user/review_user(..., personas)`), review type `persona` (人物内核不符) + code scan `persona.scan_unknowns` (person present + an `unknowns` term in the text); `ideas._context` uses `build_for`.
- **Java** (`PersonaService`, `PersonaController`, `/api/persona/**`, single background thread `persona`, polls `/api/extract/jobs/{id}` every 3 s): cards `GET /cards?keyword=&tag=` · `GET /cards/{id}` (current version as `content`) · `POST /cards/extract {name, aliases?, kind?, tags?, source{type: text|file|extract, text?, fileIds?, extractId?, entityKey?, whole?}, maxBlocks?, chunkChars?, model}` · `POST /cards/create` (blank) · `/cards/{id}/resume|stop|meta|delete`; versions `GET /cards/{id}/versions[/{no}]` · `POST /cards/{id}/versions/save {content, note}` · `POST /cards/{id}/versions/{no}/restore`; adaptations `GET /cards/{id}/adaptations` · `POST /cards/{id}/adapt {version?, novelId?, world?, wish?, model}` (requires `content.coreConfirmed`) · `GET /adaptations/{id}` · `POST /adaptations/{id}/save {content}` (re-check, back to DRAFT) · `/confirm` · `/delete` · `/apply {novelId?, role?}` (CONFIRMED only) · `/test {model, judgeConfigId?}` · `/test/cancel`; workspace `GET /novels/{novelId}` (`outdated` vs the adaptation) · `POST /novels/{novelId}/remove {name}`; chat `GET /chats?cardId=&adaptationId=&novelId=&name=` · `POST /chats/start {cardId?|adaptationId?|novelId + character{name, card, greeting?, userRole?}, mode?, scene?, inner?}` · `GET /chats/{id}` · `/chats/{id}/update|send {message, model, boost?}|regenerate|feedback {index, rating good|bad|null, reason?}|delete` · `GET /feedback?cardId=&adaptationId=`. Restart: EXTRACTING → INTERRUPTED (继续), RUNNING tests → FAILED. Model = `{source: api, configId?} | {source: gguf} | {source: local, baseId}` via `NovelExtractService.resolveModel`.
- **Tables** (`sql/persona.sql`, also in `init.sql`): `persona_card` (metadata + extraction task state, `options` = extraction params incl. pasted text, no key), `persona_card_version` (append-only, `UNIQUE(card_id, version_no)`), `persona_adaptation` (`content` / `applied` / `tests` JSON + `test_status/progress/message/job_id`), `persona_chat` (`messages` / `scene` / `character` / `drift` JSON, `summary`, `summarized_upto`). Partial updates use `LambdaUpdateWrapper` (whole-row `updateById` would overwrite a concurrently saved version / running test).
- **Frontend**: route `/persona` (sidebar 角色卡) = `views/persona/index.vue` (card list + tabs 原型卡 `PersonaEditor` / 版本 `VersionHistory` / 适配版本 `AdaptPanel` (incl. `IdentityTest` and chat) / 试聊原型), `components/persona/{ExtractDialog, TraitItem, ModelPicker, ChatPanel}`, `api/persona.js`. 实体档案 character entities have 「提取为原型」 (`EntityArchive` prop `extractId` → `/persona?extractId=&entityKey=&name=`). The workspace character-card 试聊 (`CharacterChat.vue`) now uses `ChatPanel` with `novelId` (provided by `SettingsEditor` as `ai.novelId`); Python finds the workspace persona by name / alias.
