# 试聊

和人物对话来检验他「像不像」。三种对象共用一个引擎（`persona.chat`）和一个前端组件（`components/persona/ChatPanel.vue`）：

| 对象 | 入口 | 人物设定来源 |
|---|---|---|
| 原型卡 | 角色卡页「试聊原型」 | 原型（`as_persona`：核心特征 + 规则 + 说话方式 + 原话 + 记忆）—— 原世界里的他 |
| 适配版本 | 适配版本「试聊」 | 适配版本 + 它的世界观 |
| 工作区角色卡 | 设定编辑器角色卡「试聊」（`CharacterChat.vue`） | 角色卡字段；工作区 `novel.personas` 里有同名（或别名）人物内核时一起用，世界观 = 工作区设定 |

会话存在 Java `persona_chat`，可以回看、继续、删除；模型来源 大模型 / GGUF / 本地模型（本地模型试聊只用基础模型，不加载适配器）。

## 模式

- **自由聊天**：作者和他对话；工作区角色卡的开场白作为第一句（发给模型时前面补一句「（对话开始）」，兼容要求 user 先说话的接口）。可以写「你扮演谁」。
- **场景演绎**：场景描述 + 在场人物（名字 + 动机）+ 可选「AI 旁白推进场景」。
- **采访**：问他怎么看、为什么，要求讲出想法和原因，用来检查内核是否到位。

## 回复格式

`台词（动作）〔内心〕`。`split_inner` 把〔〕里的内心拆到 `inner`，前端「显示内心」开关决定显示与否（关掉时提示词也要求不写内心）。
模型在回复开头加的「名字：」会被去掉。

## 防止走偏

- **锚点**：每轮在消息末尾再加一条 system（`anchor`）：「提醒：你是「X」。内核：前 3 条核心特征。说话方式：…。不要说出他不知道的事。」上一次检查发现走偏时，作者可以勾「下一句加强人物提醒」（`boost`），锚点再加一句「这一轮请格外贴近内核和决策规则，不要迎合对方」。
- **检索**：按最后一句话和记忆 / 示例台词的字符二元组重合，取最相关的 3 条放进 system（`retrieve`；都不相关时取 1 条），而不是把全部台词塞进去。
- **摘要**：Java 只发还没压进摘要的消息；超过 `CHAT_KEEP`（20）+ 6 条时，较早的部分和已有摘要一起压成 ≤200 字摘要（`summary` / `summarized_upto` 存在会话里，下一轮不重复压）。
- **走偏检查**：每 8 次角色回复（`DRIFT_EVERY`）做一次 JSON 检查：违背决策规则、说话不像、一味顺从、说出不该知道的事；代码另外扫 `unknowns` 泄漏。结果存在会话的 `drift`，前端显示黄色提示。

## 反馈

每条角色回复可以点「像他」/「不像他」（可写原因）。

- 适配版本的会话里「像他」→ 这句（和上一句作为情境）存进适配版本的 `examples`，之后写作和试聊都能检索到；
- 「不像他」汇总在 `GET /api/persona/feedback`（原因计数 + 例子），角色卡页列出来，供作者补行为规则。
- 工作区角色卡试聊保留原来的「存为示例对话」（追加到角色卡的「示例对话」字段，需要保存设定）。

## 和旧试聊的区别

旧版（`ideas._chat`，`kind: chat`）仍然保留给其他调用；工作区角色卡的试聊改走 `/api/persona/chats/**`：会话持久化、模式、内心、锚点、摘要、走偏检查、反馈。
